# CLAUDE.md — Fragolina

## Visione
App privata per due persone (Leonardo, Nikole): widget condivisi, mascotte (fragola originale), umore, "penso a te", disegni, mini giochi. Mai sull'App Store. Il nome è `APP_NAME` in `src/config/couple.ts`.

## Vincoli
Costo zero (nessun servizio o dipendenza a pagamento). Sviluppo su Windows (PowerShell, script Node). Solo iPhone, **iOS 16.4 o più recente** (minimo reale dello stack Expo SDK 58; il proprietario ha un iPhone X fermo a iOS 16.7). Il codice nativo non deve usare API iOS 17+ senza `if #available` e un ripiego grafico. Installazione per sideload con Apple ID gratuito (scade ogni 7 giorni). Build solo su GitHub Actions (macOS), IPA **non firmato**. Nessun personaggio o marchio esistente: i simboli della coppia arrivano in `assets/user-art/`.

## Regole di movimento (obbligatorie)
- Cancello di frequenza: le tab non si animano. Press < 150ms; sheet/toast < 300ms; piacere solo per momenti rari o azioni dell'utente.
- Tocco → molle (`motion.spring` 400/1, `springSheet` 300/0.8), velocità consegnata, rubber-band, tutto interrompibile. Non-tocco: `motion.easeOut` / `easeInOut`; mai ease-in; mai scala da 0.
- Solo `transform` e `opacity` (eccezione: elementi assoluti senza figli). Mai animare intensità blur né elevation.
- Reanimated: `useSharedValue` con `.get()/.set()` (mai `.value`); mai `setState` da gesture o scroll; `scheduleOnRN` (mai `runOnJS`) solo in `onEnd` o in `useAnimatedReaction` a soglia, mai per frame; funzioni chiamate dai worklet iniziano con `'worklet'`; `GestureHandlerRootView` alla radice.
- Aptica: tick (selezione), light (commit/snap), success (azione completata); una per azione, sullo stesso frame, mai unico feedback. Reduced motion in ogni animazione (`useTheme().reduceMotion`).

## Migrazioni Supabase: le applica Claude (`npm run db:apply`)
- **Non far incollare SQL a Leonardo.** Dopo aver aggiunto una migrazione e rigenerato `supabase/sessioneN-*.sql` (`npm run backend:sql`), lancia `npm run db:apply`: applica in ordine i file `supabase/sessioneN-*.sql` non ancora applicati (o cambiati) e li registra in `public.app_migrations` (nome + sha256). I file sono ripetibili. `npm run db:apply -- --status` mostra lo stato senza toccare nulla; `-- nome.sql` forza la riapplicazione di un file. Poi `npm run backend:check` deve dare tutto PASS, nessuna riga `MANCA`.
- La stringa `SUPABASE_DB_URL` (Session pooler, IPv4, porta 5432, regione **eu-north-1**, host `aws-0-eu-north-1.pooler.supabase.com`, utente `postgres.<ref>`) sta SOLO in `.env.local` (non su git, non nei log). Se manca: chiedi a Leonardo la password del database (una volta) e lancia `SUPABASE_DB_PASSWORD='…' npm run db:setup` (prova le regioni, salva la stringa, non salva la password). Password persa: Supabase → Project Settings → Database → Reset database password.
- Una nuova sessione con una nuova migrazione: crea `supabase/migrations/<data>_<nome>.sql`, aggiungi la generazione di `supabase/sessioneN-<nome>.sql` in `scripts/build-sql.mjs`, poi `db:apply` e `backend:check`.

## Sessione 8 — regole utili
- **Suoni:** un suono per azione dell'utente, sullo stesso frame dell'aptica (`sound="…"` su `Button`/`Sticker`/`StickerPressable`, oppure `play("…")` accanto a `haptics.*`), mai come unico feedback, mai sulle tab/scroll, mai per eventi in arrivo. Nuovo suono: aggiungi la sintesi in `scripts/make-sounds.mjs`, `npm run sounds:gen`, il `require` in `soundSources.ts`, e il test `tests/sound.test.ts` controlla da solo che esista il file, sia < 0,6 s / < 60 KB / −6 dBFS e che sia usato. `play` non deve mai lanciare. Audio: **mai** `playsInSilentMode: true` né `allowsRecording`.
- **Movimento:** le tab non si animano (né contenuto, né macchia, né glifo); ogni `withTiming` ha `easing: motion.easeOut`/`easeInOut` esplicito; i loop infiniti si fermano fuori dal primo piano (`useScreenFocused`); lo scheletro è invisibile per 150 ms e il contenuto che arriva dopo si dissolve con `Reveal`; le feste rare passano da `useCelebrated.firstTime(chiave)` (mai un `Set` in memoria: si ripeterebbero a ogni avvio).
- **Rete e coda:** lettura dello stato (`resync`) e spedizione della coda (`flush`) passano dal mutex `io` di `createCoupleStore`: non spostare una `getState` fuori da lì. `engine.networkBack()` è l'unico modo per saltare il backoff. Il badge di stato è UNO (`LinkBadge` nella radice): non metterne altri in schermata.
- **Store persistiti:** ogni store ha `version` e `migrate` difensivo (`migrateSettings`, `migrateCouple`, `migrateCelebrated`, `migrateDraft`); cambi il formato? alza la versione e aggiungi la prova che uno stato vecchio si carica (`tests/session8.test.ts`).
- **Pulizia dei pensieri:** `pings` tiene solo gli ultimi 90 giorni; i totali stanno in `ping_archive` e vanno sommati in `get_state`/`get_month` (già fatto). Se ridefinisci una di queste due funzioni in una migrazione nuova, **parti dalla versione di `20261120000001_rifinitura.sql`**, non da quella vecchia.
- **Errori:** ogni rotta di `app/` esporta `withErrorBoundary(Schermata, "nome")`; non aggiungere rotte "nude". Il fallback non usa mascotte né store.
- **Accessibilità:** `tests/a11y.test.ts` fallisce se un controllo toccabile (Pressable, StickerPressable, Sticker con `onPress`, TextInput) non ha `accessibilityLabel`, se un Pressable RN grezzo non ha `accessibilityRole`, o se un'immagine non è descritta/nascosta.
- **Icona e splash:** `npm run icons` rigenera `assets/icon.png` (variante scelta in `CHOSEN`), `splash-mark.png` e `grain.png`; lo splash nativo e `SplashOverlay` usano lo stesso marchio (200 pt) e lo stesso rosso `#FF2D55`: tienili uguali. `assets/user-art/app-icon.png` (1024×1024, senza trasparenza) vince sempre. L'anteprima delle varianti: `node scripts/make-icon.mjs --variants` → `docs/shots/session8/icon/`.
- **Versione in Noi:** `BUILD_NUMBER` e `GIT_SHA` arrivano dal workflow `build-ipa.yml` (`github.run_number`, `github.sha`) a `app.config.js` (`extra`).
- **Prove:** `npm run e2e:s8` (serve `npm run web` con `.env.local` spostato, Metro riavviato, `CHROME_LIBS`; scrive in `docs/shots/session8/r<ROUND>/`; con `?fontScale=1.5` nel browser si simula il testo grande). `npm run e2e` esegue ora anche questa.
